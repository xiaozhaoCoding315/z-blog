# 墨与纸：博客改版设计

日期：2026-11-04
状态：已确认

## 问题

当前站点是「科技感模板」的典型产物：紫色→青色渐变、玻璃拟态、光晕球体、星空背景、四宫格统计、技能标签墙。信息被均匀摊在首页，没有主次；同一份内容在首页、`/skills`、`/about` 三处重复；十个导航项互相稀释。视觉与内容都缺乏个人辨识度。

## 定位

**写作型个人博客。** 读者是同行与招聘方。首页唯一的任务是把人送进一篇文章，而不是展示站点有多少功能。

## 视觉方向

### 色彩

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| paper | `#EEF0EB` | `#161815` | 页面底色 |
| ink | `#1B1D1A` | `#E8E6DE` | 正文 |
| ink-muted | `#6B6F68` | `#9A9E95` | 次要信息 |
| accent | `#1F5C55` | `#5FA79B` | 唯一强调色 |
| vermilion | `#A8432E` | `#C4644D` | 仅「置顶」标记 |
| rule | `#DCDDD5` | `#2A2D27` | 分隔线 |

不引入渐变、玻璃、光晕、噪点、网格背景。**默认主题改为亮色**，暗色保留手动切换。

### 字体

- 标题：思源宋体，`@fontsource-variable/noto-serif-sc` 自托管（101 个 unicode-range 分片，单字集约 58KB，浏览器按需下载）。不使用 Google Fonts 外链——中文访客无法加载。
- 正文：Geist + 系统中文字体栈，不新增第二个中文字体。
- 元信息：Geist Mono。日期、计数、标签一律等宽。

标题字距 `-0.02em`。首页主标题 52px，文章页标题 32px，区块标题 22px。

### 布局：左边距

签名元素。一个常驻左栏，用等宽字承载真实元数据（时间范围、文章数、RSS、GitHub），在桌面端与正文并排，在移动端收成顶部一行。它像书的页边批注，编码真实信息而非装饰。

文章列表不使用卡片：行之间一条细线，日期在左、标题在右，悬停时标题转为深青并加下划线。

## 页面调整

| 页面 | 处理 |
|---|---|
| 首页 | 重写：左边距 + 自我介绍 + 置顶文章 + 全部文章 + 项目清单 |
| 文章详情 | 保留目录、进度、点赞、浏览量、评论；标题换宋体，元信息栏改细线分区 |
| 归档 | 移除竖线渐变与玻璃年份牌，改为「年份 + 细线 + 行」 |
| 关于 | 合并 `/skills` 能力清单，移除 GitHub 热力图 |
| 项目 | 移除玻璃卡片，改条目式；保留 featured 亮点列表 |
| 博客列表 | 移除圆角胶囊筛选，改细线标签 |
| `/interview` | 保留页面与全部在途工作，移出主导航，仅页脚入口 |
| `/guestbook`、`/changelog` | 同上，仅页脚入口 |
| `/skills`、`/stats` | 删除页面 |

主导航：文章 / 归档 / 项目 / 关于，加搜索、主题切换、GitHub。

## 移除清单

组件：`components/home/*`（starfield、count-up、live-metrics、type-rotate）、`components/stats/*`、`components/about/github-heatmap.tsx`、`components/changelog/activity-heatmap.tsx`（`/changelog` 仍在使用，保留组件但改为细线样式）。

工具类：`glass`、`bg-grid`、`bg-noise`、`glow-orb`、`card-hover`、`text-gradient`、`animate-float-slow`、`caret-blink`。删除时同步清理所有引用，不留死代码。

动效：仅保留文章列表滚动入场（40ms 错峰）与链接悬停。移除 ping 呼吸点、星空、打字机、渐变流动。

## 技术约束

- 字体走 npm 依赖 + `@import`，保证离线可用与 Docker 构建一致。
- 不改变任何 API 路由与数据库结构；点赞、浏览量、AI 问答、搜索继续工作。
- 修复 `src/config/portfolio.ts:38` 的重复 `],` 语法错误——当前 `tsc --noEmit` 报 `TS1005`，阻塞构建。
- 面试题库 200 道题、`mastery` 上云、`review` API 全部保留，仅调整入口位置。

## 验收标准

1. `npx tsc --noEmit` 无错误，`npm run build` 通过。
2. 首页在 1440px 与 375px 下均无横向溢出，主导航不超过 4 项。
3. 亮色为默认，暗色可切换，两套配色均满足正文对比度 ≥ 7:1。
4. 全站不出现渐变背景、玻璃模糊、光晕球体。
5. 中文标题实际渲染为宋体（非系统默认衬线）。
