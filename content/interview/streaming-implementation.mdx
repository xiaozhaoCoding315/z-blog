**全链路流式**：LLM API 返回 SSE（chunk 流）→ 服务端逐 chunk 转发 → 浏览器 EventSource/fetch ReadableStream 增量渲染——**TTFT（首字时间）从 5s 降到 1s 内，体验质变**。

**SSE vs WebSocket**：
- **SSE**：单向（服务端→客户端）、HTTP 原生、自动重连、文本帧——**LLM 对话场景首选**（本站就是）
- WebSocket：双向、二进制、需要心跳与升级协议——多轮实时协同（语音、协同编辑）才需要

**前端要点**：fetch + ReadableStream 手动解析（EventSource 不支持 POST/自定义头）、渲染节流（rAF 批量追加而非逐字符 setState）、Markdown 边流边渲染的兼容（未闭合代码块容错）。

**后端要点**：反向代理别缓冲（nginx `X-Accel-Buffering: no`）、超时与断线重连策略、finish 信号与错误中断的区分。
