---
question: 一次 HTTP 请求在 Spring MVC 里的完整流程？过滤器和拦截器的区别？
category: Spring
difficulty: 中
tags: [SpringMVC]
---
**流程**：DispatcherServlet 接收 → HandlerMapping 找 Handler（含拦截器链）→ HandlerAdapter 执行 Controller → 返回 ModelAndView → ViewResolver 解析视图 / @ResponseBody 走 HttpMessageConverter（Jackson 序列化）→ 渲染响应。

**过滤器 vs 拦截器**：
- 过滤器是 **Servlet 规范**，拦截器是 **Spring 机制**
- 执行顺序：Filter pre → Interceptor preHandle → Controller → Interceptor postHandle → Filter post
- 过滤器能拿到原始请求/响应流，拦截器能拿到 Handler 信息（哪个方法、参数）
- 选型：编码/跨域/CORS/XSS 过滤用 Filter；登录态/权限/日志埋点用 Interceptor

**追问**：拦截器 postHandle 在异常时不执行，afterCompletion 总执行（清理资源的正确位置）。
