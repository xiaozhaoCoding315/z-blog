---
question: 写好 Prompt 的核心原则有哪些？
category: Agent / LLM 应用
difficulty: 易
tags: [Prompt 工程]
companies: [字节, 阿里]
---
**六个核心原则**：
1. **角色与目标**：先定身份（"你是资深 Java 面试官"）和任务边界
2. **给参考示例（Few-shot）**：一两个输入输出示例比十句描述有效
3. **结构化拆解**：复杂任务分步骤（思维链 "let's think step by step" 提升推理）
4. **明确输出格式**：JSON Schema/表格/字数限制——"输出不超过 120 字"比"简洁"可控
5. **负面约束 + 兜底**：禁止事项、资料没有时怎么办（"说不知道，不要编造"）
6. **迭代评测**：Prompt 是代码——建测试集，改动跑回归，别凭感觉调

**工程化认知（区分玩家与工程师）**：Prompt 版本管理、A/B 对照、把失败 case 沉淀成规则——"Prompt 是需要单元测试的产品功能"。
