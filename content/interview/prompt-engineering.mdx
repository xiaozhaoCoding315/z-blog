---
question: 写好 Prompt 的核心原则有哪些？
category: Agent / LLM 应用
difficulty: 易
tags: [Prompt 工程]
companies: [字节, 阿里]
---
**六条，前两条最值钱**：

1. **角色+边界**："你是资深 Java 面试官，只问后端问题"——身份决定视角和语气
2. **给例子（Few-shot）**：一对输入输出示例胜过十句形容词；想要什么格式，直接贴一个
3. **分步思考**：复杂任务让它"先分析→再方案→最后风险"，一步到位容易跳步出错
4. **输出格式显式约束**："输出 JSON，字段为 title/tags"比"规范输出"可控百倍
5. **负面约束+兜底**："不要编造"；"资料没有就说不知道"——给拒答留台阶
6. **当代码管理**：Prompt 入版本库、建测试集、改动跑对照——凭感觉调 prompt 的时代该结束了

**实用小技巧**：让模型先复述任务（"开始前用一句话确认你的理解"）——理解偏差当场暴露，比返工便宜得多。
