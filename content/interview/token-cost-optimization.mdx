**先建立账本意识**：成本 = 输入 token + 输出 token（输出通常贵 3-5 倍）。一个 Agent 一次任务循环 5 轮，每轮带全部历史——**上下文像滚雪球，第 5 轮付着第 1 轮的钱**。

**六个省钱杠杆（按性价比排）**：

1. **缓存（上题）**：语义缓存 + prompt 前缀缓存——重复问题零成本
2. **模型分级路由**：简单任务小模型、复杂任务大模型——分类/抽取/简单问答走 flash 级（便宜 10 倍+），只有多步推理上旗舰。**规则路由（按任务类型）或小模型当调度员**
3. **上下文瘦身**：历史对话及时摘要压缩；工具返回值截断（"返回前 50 行+总数"）；检索片段宁精勿多（rerank 后取 top3 而不是 top10）
4. **输出约束**：max_tokens 封顶 + prompt 要求简洁（"不超过 100 字"）——输出贵，长废话就是烧钱
5. **结构化中间结果**：Agent 每轮只需要"结论+关键数据"，别让模型复述任务背景
6. **批处理**：离线任务（文档打标、批量摘要）用 batch API（五折、24 小时返回）——不赶时间的活全走它

**监控兜底**：按功能/用户/模型维度记账——**成本可视化是优化的第一步**（很多团队根本不知道钱花在哪）。

**点睛**："token 优化的顺序是**先砍量（缓存/路由/瘦身）再谈价（换模型）**——顺序反了就是优化了个寂寞"。
