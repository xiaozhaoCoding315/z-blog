**ReAct 循环 = 思考(Reason) → 行动(Act) → 观察(Observe) 循环**：

1. **输入组装**：系统提示（角色/规则/工具清单 JSON Schema）+ 历史消息 + 用户目标
2. **模型决策**：LLM 输出「调用哪个工具 + 参数」（Function Calling 是模型微调出的结构化输出能力，本质是把工具 schema 当作受约束的解码空间）
3. **工具执行**：宿主代码执行（查库/调 API/跑沙箱），拿到结果
4. **观察回填**：工具结果作为 tool/message 角色追加进上下文，进入下一轮
5. **终止条件**：模型输出最终答案 / 达到最大轮数 / 触发停止工具

**工程要点**（区分背书与实战的关键）：工具描述要写给模型看（清晰的不变量与失败模式）、控制上下文长度（历史裁剪/摘要）、每轮校验参数、失败信息要可行动（「城市名不完整，请包含省市」优于「参数错误」）、循环上限防失控。

**我做过的话术**：可以结合自己 Nova Agent 的经验——比如红绿测试工具的失败输出直接回喂给模型自我纠错。
