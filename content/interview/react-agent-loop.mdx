question: 描述一个 Agent 的完整执行循环（ReAct / Function Calling）？

tags: [Agent, Function Calling]

**一图流**：目标进 → LLM 想"该用哪个工具" → 宿主执行工具 → 结果塞回上下文 → LLM 再想 → 循环到出答案。

**五步拆解**：

1. **组装输入**：系统提示（角色+规则+工具清单，每个工具带 JSON Schema）+ 历史 + 用户目标
2. **模型决策**：Function Calling 的本质是模型经过专门训练，该调工具时输出**结构化调用请求**（工具名+参数 JSON）而非闲聊
3. **宿主执行**：真正调 API/查库/跑命令的是**你的代码**——模型只出主意，动手的永远是宿主
4. **观察回填**：工具结果以 tool 消息追加进上下文（模型"看到"了结果）
5. **终止条件**：输出最终答案 / 触发停止工具 / **最大轮数兜底**（必须有，防无限循环烧钱）

**实战分水岭**（背书者说不出）：工具描述写给模型看（何时用、失败长什么样）；**失败信息要可行动**——"城市名不完整，请带上省市"能让它自我纠正，"参数错误"只会让它瞎猜；每轮校验参数；历史太长要裁剪。

**收尾**：拿自己项目举例——"我做的 Agent 测试失败输出直接回喂，模型根据报错自我纠错，最多三轮"。
