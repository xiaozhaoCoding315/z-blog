---
question: 重载（Overload）和重写（Override）的区别？
category: Java 基础
difficulty: 易
tags: [多态]
---
**重载**：同一个类里，方法名一样但**参数不同**（个数、类型、顺序）。它发生在**编译期**——编译器看你传的参数类型就决定调哪个，跟你运行时传的是什么对象无关。像公司前台按"访客类型"分流：快递走 A 口、面试者走 B 口，看的是你**进门时展示的身份**。

**重写**：子类把父类的方法重新实现，**参数必须一模一样**。发生在**运行期**——父类引用指向子类对象时，调的是子类的版本，这就是多态。像儿子继承父亲的店铺但改了经营方式，客人拿着"老张家的店"的招牌找过来，实际享受到的是新做法。

**两个易错点**：

1. 重载跟返回值无关——只有返回值不同编译器分不清该调谁，直接报错
2. private / static / final 方法不能被重写：private 父类看不见；static 属于类不属于对象（子类同名只是"隐藏"）；final 明令禁止

**一个经典坑**：`List<String> list = new ArrayList<>(); list.add("x")` 调的是 ArrayList 的 add——因为 add 是被重写的（运行期看实际类型）；但如果参数是 null，重载解析会选"最具体类型"的那个版本，容易掉坑。
