---
question: temperature 和 top_p 参数怎么调？什么场景用什么值？
category: Agent / LLM 应用
difficulty: 易
tags: [参数调优]
---
**两者都在控制"随机性"，机理不同**：

- **temperature**：给概率分布"加温/降温"——低温（0.1）高概率词垄断输出（**保守稳定**）；高温（1.5+）分布摊平冷门词都有机会（**发散脑洞**）
- **top_p（核采样）**：只在**累计概率前 p 的词里抽**——top_p=0.1 只从最稳的 10% 里选，长尾彻底出局

**按场景给值**（背这张表就够）：

| 场景 | temperature | 理由 |
| --- | --- | --- |
| 代码生成、SQL、JSON 输出 | 0 ~ 0.2 | 要确定性，一个字都不能飘 |
| RAG 问答、知识总结 | 0.2 ~ 0.5 | 忠实资料，别自由发挥 |
| 常规对话/文案 | 0.5 ~ 0.7 | 有点灵活但不跑偏 |
| 创意写作、头脑风暴 | 0.8 ~ 1.2 | 越野越好 |

**实用经验**：**调一个别调俩**（两个一起动效果不可预期）；temperature=0 也非完全确定（数值精度/批处理差异），要稳定输出配合 seed；**function calling 场景低温甚至 0**——参数抽取要的是准不是浪。

**追问预备**：还有 top_k（只在前 k 个候选里抽）和 repetition_penalty（重复惩罚）——工程上 temperature 是最常用的那个旋钮。

**一句话**："temperature 决定它多敢说，场景决定它该多敢"。
