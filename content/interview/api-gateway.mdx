question: 网关的职责有哪些？和负载均衡器的区别？

**网关核心职责**：统一入口、路由转发、**认证鉴权（JWT 校验/限流）**、协议转换、灰度分流（按 header/权重）、日志与链路追踪埋点、防攻击（黑名单、防重放）。

**实现**：Spring Cloud Gateway（WebFlux 响应式）、Kong/APISIX（OpenResty，插件生态）、Nginx+Lua。

**与 LB 区别**：LB（LVS/Nginx）工作在四层/七层做流量分发；网关在七层之上理解**业务语义**（路由规则、鉴权、灰度）。典型架构：DNS → SLB → 网关集群 → 微服务。

**追问**：网关要高可用——多实例 + 前置 LB；网关不能有重业务逻辑（保持轻量稳定）。
