---
question: Java 是值传递还是引用传递？
category: Java 基础
difficulty: 中
tags: [值传递]
companies: [所有大厂]
---
**结论只有一个：Java 永远是值传递**。 confusion 来自"对象的值"是引用（地址）。

**两个例子讲透**：

```java
void change(Person p) { p.name = "新名字"; }     // 改的是对象内容——生效！
void replace(Person p) { p = new Person(); }     // 换的是副本指向——不生效！
```

**为什么第一个生效**：传进去的是"地址的复印件"——复印件和原件指向同一个房子，你拿着复印件去装修，房子真的变了。

**为什么第二个不生效**：你把复印件上的地址划掉写了个新地址——**原件不受影响**，方法结束后复印件销毁，新对象无人知晓。

**C++ 的引用传递（&传参）是什么样**：传的是"房子钥匙本体"而非复印件——在里面换房子（重指向）原件也跟着变。Java 没有这个能力。

**一句话**：Java 传对象的"地址复印件"——改内容双方可见，改指向只影响自己。面试就靠"复印件装修 vs 改地址"这个比喻讲清。
