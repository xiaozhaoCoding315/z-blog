question: 类加载的过程分几步？每步做什么？

**加载 → 验证 → 准备 → 解析 → 初始化**（后四步合称连接）：

1. **加载**：读取字节流生成 Class 对象
2. **验证**：文件格式/元数据/字节码/符号引用四道检查，防恶意字节码
3. **准备**：静态变量分配内存并**置零值**（static int a=1 此刻 a=0）；static final 常量直接赋值
4. **解析**：符号引用转直接引用（可延迟到首次使用，支持动态绑定）
5. **初始化**：执行 `<clinit>`（静态变量赋值+静态块，**编译器按源码顺序收集**）；JVM 保证 clinit 线程安全——**静态单例和静态内部类单例的原理**

**触发初始化的时机**：new、访问静态字段/方法、反射、初始化子类连带父类——注意「访问 static final 常量（编译期已知）」不触发。
