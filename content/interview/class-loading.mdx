question: 类加载的过程分几步？每步做什么？

五步走：**加载 → 验证 → 准备 → 解析 → 初始化**。重点在后三步，每步都有考点。

**准备阶段有个经典坑**：`static int a = 1;` 这时候 a 的值是 **0 不是 1**！准备只做"划座位+置默认值"，真正赋值 1 要等初始化阶段执行静态代码。但如果是 `static final int A = 1`（编译期常量），准备阶段就直接给 1。

**初始化阶段执行 `<clinit>`**——编译器把所有静态变量的赋值语句和静态代码块，**按你写代码的顺序**拼成一个大方法执行。这里藏着两个高频知识点：

1. **JVM 保证 clinit 线程安全**（只执行一次、别的线程阻塞等它）——所以**静态内部类单例**才成立：

```java
class Singleton {
    private static class Holder { static Singleton INSTANCE = new Singleton(); }
    public static Singleton get() { return Holder.INSTANCE; }  // 第一次调用才加载 Holder，才创建实例
}
```

2. 父类静态块先于子类执行（父类先初始化）。

**什么会触发初始化**：new 对象、调静态方法/静态变量、反射——注意 `访问 static final 常量`（比如 `int A = 1` 这种编译期能确定的）**不会触发**，因为常量在编译期就被拷进调用方了。
