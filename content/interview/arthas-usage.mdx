**Arthas = 线上 JVM 的"随身工具箱"**——不改代码、不重启，一条命令挂进运行中的进程。专治"本地好好的线上才有问题"。

**高频六连**（现场背出来）：

- **`thread -n 3`**：最忙的 3 个线程在干嘛（CPU 高一键定位，不用再 jstack 手动换算十六进制）
- **`dashboard`**：总览面板——线程/内存/GC 一屏全览
- **`jad 类名`**：反编译——**确认线上跑的是不是我改的那版**（经典场景：改了没部署/部署了没生效，jad 一看便知）
- **`watch 类 方法 '{params, returnObj}'`**：**现场偷看方法出入参**——不用加日志重新发布
- **`trace 类 方法`**：方法内部每行耗时拆解——慢接口是哪一步慢，一图看清
- **`ognl`**：直接执行表达式，动态改日志级别（`logger --name com.x --level debug`）线上开 debug 不重启

**实战剧本**：接口偶发 4 秒——trace 跟一次发现卡在第三方 HTTP 调用 → watch 看参数发现特定租户触发慢分支 → 定位是对方接口对某参数慢。**全程没碰代码没重启**。

**和 jstack/jmap 的关系**：底层做同样的事，但 Arthas 免去"记命令+转格式+传文件"的手工活，还有 WebConsole 团队共用——生产排障效率的数量级差异。
