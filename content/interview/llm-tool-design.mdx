**核心认知：工具描述是写给模型看的说明书**，不是给开发者的 API 文档。七条：

1. **说清"什么时候用我"**："当需要实时信息或资料中没有的事实时使用"——比"执行搜索"有用
2. **参数越少越稳**：能用枚举别给自由文本
3. **错误信息要可自我纠正**："城市参数需含省市，如'浙江杭州'"——模型看到能自己修；返回"invalid input"它只能瞎猜
4. **返回精炼**：一万行截成"摘要+总数+分页"；上下文是稀缺资源
5. **危险操作加人审**：删除/支付/写库——Agent 提案，**人批准才执行**
6. **权限最小化**：工具内部做鉴权，每个工具只能碰白名单资源——别信模型的"自律"
7. **幂等+超时**：模型可能重复调用，重试不能双倍扣款

**反面教材**：一个"万能工具"50 个参数；让模型拼 SQL 字符串（注入温床——应给参数化查询工具）。
