**CDN = 把你的内容复印几万份放到离用户最近的机房**。用户请求 DNS 解析时，**CDN 的智能 DNS 把用户调到地理/网络最近的一个边缘节点**（北京用户到北京节点、广州用户到广州节点）——物理距离近了，延迟从 100ms 降到 20ms。

**缓存命中 vs 回源**：

- **命中**：边缘节点已有这份文件 → 直接返回（毫秒级，最理想）
- **回源（miss）**：节点没有 → 去源站（你的服务器）取一份，**缓存到节点**再返给用户——第一个用户慢一点，后面的全快
- 中间还有一层：边缘→区域中间节点→源站（多级缓存）

**关键机制——缓存过期与刷新**：静态资源靠 **Cache-Control**（浏览器缓存一份）+ CDN 节点缓存（TTL）；**版本化 URL 是缓存神器**——文件名带 hash（app.a3f9c2.js），内容变文件名变，旧缓存自然失效，**彻底告别"发布了用户还看到旧版"**。

**什么放 CDN**：静态资源（js/css/图片/视频）放；动态 API 不放（但有"动态加速"——选路优化路由）。

**实践细节**：CDN 带宽费心疼的——大文件（视频）重点优化；防盗链（Referer 校验/签名 URL）防别人白嫖你的流量；灰度发布时注意 CDN 多级缓存的生效延迟。
